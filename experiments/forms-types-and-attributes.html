Why does every input need a label?

For accessibility. You can't rely on just a 'placeholder' in an input element, or else screen readers won't be able to tell where you are. Besides, there's also the annoying side effect that the moment you start typing, you lose what the text input is for.


What. can you do with the attributes type, autocomplete, inputmode, enterkeyhint

A lot of things. With type you determine what kind of input it is. A button, a text field, a color picker, etc. With autocomplete, you determine what the browser will prompt the user with, making it more accessible and easier to fill in the form. With inputmode, you can make it easier what type of text should enteer the input element, especially on mobile devices in order to prompt the correct keyboard.
