why i love gruvbox

gruvbox is a pastel, 'retro groove' theme i've been using for years now, and really, most of my waking life.

that's no exaggeration or anything. it's just so comforting to my eyes, and i haven't found a reason to dislike it.

the colours remind me of an era i've never experienced myself, and using any interface that supports it feels as if the UI was a cozy coffee shop.

another reason why i'm so happy with the theme, is that it's open-source and widely supported by thousands of applications. that means no matter what open source tool i'm using, someone likely made a gruvbox theme using it, and if not, i can just refer to the GitHub repository and make my own.

but i will admit... it's not the perfect theme. the colour contrast on light mode isn't the greatest, and to improve it i've increased the font-weight to 500 when they are used, similar to semi-bold which makes it more visible without being overbearing.

regardless, it's because of this unconditional love for Gruvbox, that I'm using it as the default theme for my digital garden.
