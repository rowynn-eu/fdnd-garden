
As I've been told by my lecturers, there are some good and bad practices in the field of web development.

# Good Practices
- Good SEO is making smart use of semantic HTML so that both Search Engines and narrow AI aggregators can find and digest your content easily. 
- Try to have good semantic structure in your work.
- HTML is for content.
- CSS is for design.
- JavaScript is for interaction, however, when possible, use CSS first.
- Good HTML is one made entirely of semantic tags.
- Using inline, intern and extern CSS as appropriate for the specific project.
	-  With the exception fo some edge cases, you'll almost always use extern CSS.

# Bad Practices
- Using Javascript voor content (such as adding text)
- Using IDs over creating a class in CSS
- Using Divs for everything
- Using !important in your CSS
- Using style="" attribute
- Using <b> or <i> over <em> and <strong>
