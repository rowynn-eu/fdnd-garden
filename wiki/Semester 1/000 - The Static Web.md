In the first semester we'll be interacting very little with JavaScript, only to highlight some interactions for websites that aren't possible just yet with pure CSS.

This degree is based on achieving *competency* with a given subject or field.

In dutch, it reads the following:
> De student gebruikt fundamentele principes van het web voor het ontwerpen en ontwikkelen van eenvoudige gebruiksvriendelijke interactieve toepassingen voor het web.

Which, translated into easy english means to use the fundamentals of a web developer to great simple, user-friendly websites / applications.
