How This Site Is Made

all content on this site, unless otherwise noted (such as a quote), is written by hand by me, rowynn!

developing the website

the development of this website is pretty straightforward. everything is written and built by hand using HTML and vanilla CSS and JS. if it isn't broken, why fix it?

there are some edge cases though. e.g. ./wiki using JS to parse markdown to viewable HTML with a table of contents in an <aside>, which some may consider unnecessary as you could just write your notes in HTML, but.. i use obsidian.md in my ./wiki directory to take my notes...

the website itself is hosted through GitHub pages on this repository, pointing to this subdomain fdnd.rowynn.eu, away from the main webstie which desperately (as of writing this) needs a proper portfolio design.

there's also a robot.txt file in the root directory that tells scrapers to buzz off...

lastly, as encouraged by Sanne, i'm trying to avoid making classes and using semantic HTML whenever possible.

eventually, it's important to me that thsi website is WCAG compliant, as i'm an a11y.
