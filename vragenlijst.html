  1. 🟢 Ik weet hoe ik met GitHub iteratief kan werken, gebruik issues en sub-issues, en ik kan uitleggen wat een fork, clone, commit, push, pull, merge en conflict inhouden.

    Met GitHub kan je issues aanmaken, het een label geven, en het gebruiken als bewijslast voor het werk wat je hebt gemaakt. Om dit te kunnen doen, moet je eerst een respository maken, dit doe je door de leertaak te forken, en daarna het te clonen naar je eigen computer zodat je kan beginnen met het schrijven van code.

    Telkens als je klaar bent met een taak, kan je een commit maken (en koppelen met een # aan een issue). Wanneer je bereide ben, kan jij je werk pushen, live zetten, en testen. Zo volg je het DLC.

    Elementen bevatten content en zijn omringd met tags. Die tags kunnen attributen hebben, zoals href="".

    In CSS, zijn selectors de manier welke HTML element je wilt aanpassen en het vormgeving geven. Met properties geef je aan wat precies veranderd, en met values/units geef je de waarde aan wat veranderd wordt. Verder zijn combinators een handig manier om wat specifieker te zijn welke element(en) je wilt aanpassen.

    Voorbeeld: Druk op CMD+U / CTRL+U of rechtermuis om de context-menu te bekijken en de source code van deze pagina te lezen.
